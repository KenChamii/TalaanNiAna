Most sari-sari stores run on a notebook. It records what was sold but never what it cost, so the owner knows the day took three thousand pesos and has no idea how much of that was theirs. This is the notebook, kept properly.

A real store with two weeks of sales. No sign-up, nothing to install. The API sleeps when idle, so the first load can take a minute.
